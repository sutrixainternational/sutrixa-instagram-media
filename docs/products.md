## Rizstay (restaurant.rizstay.com) - Hospitality OS for hotels & restaurants
- Tagline: "Run your whole hotel from one calm screen."
- Front desk: live room board + timeline, check-in/out, block rooms, guest codes, running live folio
- Billing: GST-ready bills, discounts before tax, CGST+SGST or IGST auto-calculated, complimentary stays, ONE consolidated bill at checkout
- Restaurant: table + room orders become kitchen tickets (KOTs) on a kitchen display: New / Preparing / Ready
- Guest portal: table QR menu -> browse & order; private stay code -> stay, amenities, folio
- Inventory: orders deduct recipe ingredients ("stock by recipe"), purchases restock, waste log records loss + who logged it
- Roles: one sign-in, dashboards for Owner, Manager, Front Desk, Kitchen, Housekeeping, Admin
- Reports: sales, purchases, bills, folios, filter by date, export to Excel
- Live view: check-ins, kitchen orders, settled bills update on every screen in real time
- Setup: 3 steps (property + owner login -> add rooms/dishes/stock/staff -> everyone signs in). No installs, no servers; browser on desk PC, kitchen tablet, manager's phone
- Security: passwords hashed server-side, each hotel's data kept apart, syncs across devices
- NOT on site: pricing, customer names, stats
- WEEK 1 ERRORS: "housekeeping auto-dispatched" and "guests check in from their phone" are NOT site claims
